# Project log

How we keep track of the Theme 5 work.

| File | What goes in it | When to update |
|---|---|---|
| [STATUS.md](STATUS.md) | Where we are, what's blocked, next steps | Whenever the state changes |
| [WORKLOG.md](WORKLOG.md) | Dated entries of what was done | End of every working session |
| [DECISIONS.md](DECISIONS.md) | Decisions with the reason and who made them | When a choice is made |
| [SCORES.md](SCORES.md) | Every scored run and where its logs are | After each run |
| [GEMINI_TASKS.md](GEMINI_TASKS.md) | Light tasks for Gemini CLI (junior assistant) and its results | When assigning or finishing a task |
| `runs/` | Raw logs and reports from benchmark runs, one folder per run (`YYYY-MM-DD_<config>/`) | After each run |

Plans live at the repo root: `BUILD_PLAN_FDB_V3.md` (current), `BRIEFING.md` and `RESEARCH.md` (participant-kit era).
