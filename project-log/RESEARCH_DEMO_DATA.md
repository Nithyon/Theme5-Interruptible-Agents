## Recommendation

1. Best sources.
   - Home, real audio: SLURP (real speakers, CC BY-NC 4.0 audio, about 6 GB) or Fluent Speech Commands (real, 30,043 utts, but NoDerivatives + sign-up). Snips SmartLights is closest for lights only (form sign-up).
   - Car and home in one place: Audio2Tool (Smart Car + Smart Home tool queries), but TTS, not real speech; needs a licence check on its repo.
   - Car text: KVRET is navigation/POI text only.
   - Honest gap: none has our exact tools (EV charging, roadside, washer, find phone, service centre), and none of the real-audio sets has mid-sentence self-corrections; only FDB v3 does, and that is off limits.
2. Non-overclaiming use: sample N real utterances (fixed seed, list the ids), map each to one of our tools by a published rule file, report accuracy on that sample, and state that tool labels are our mapping, not the dataset's. Say audio is real vs TTS. Attribute the dataset in the video. Do not edit audio if licence is ND.
3. Not possible tonight: Fluent Speech Commands and Snips need form sign-up; Switchboard needs LDC agreement; all real-audio sets found are NonCommercial or research-only, so use in a public video needs the licence read carefully or authors' permission; Audio2Tool licence and repo unverified.
4. FDB v1/v1.5 audio vs v3: compatible only if the audio is from the v1_v1.5 folder and separate from the v3 files. Check that no v1 clips overlap v3 content and that the NonCommercial licence permits a demo; v1 has no tool commands anyway.
