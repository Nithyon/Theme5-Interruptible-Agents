## Where FDB-v3 sits
It's the only benchmark in this table that combines **all three** of: (1) real human disfluent speech (not synthetic TTS), (2) chained multi-step tool calls with 4 state-changing APIs, and (3) full-duplex real-time streaming through an actual voice pipeline (not text transcripts fed to an LLM). VoiceAgentBench and BFCL Audio are the closest audio-native tool-calling comparisons, but neither is full-duplex/streaming in the way FDB-v3 is (both are single-shot spoken queries, not a continuous room with interruption). τ2-bench's new voice mode is the closest architectural sibling (LiveKit-style real-time streaming, tool-using agents) but its published numbers found so far are text-mode τ-bench results, not the new voice variant's — no voice-mode published numbers were found in this pass.

## Which ones we could realistically report on by 30 Sep
- **FDB-v3**: this is the scored benchmark — already in progress.
- **τ2-bench voice mode**: plausible in principle (our LiveKit agent could in theory plug into "realtime providers OpenAI, Gemini, xAI" per its README), but **not attempted and not recommended before the deadline** — it's a different tool schema (retail/airline/telecom domains, not our 12 FDB-v3 tools), so entering it would mean writing new tool bindings from scratch. Not worth the time given the freeze at 18:00.
- **BFCL Audio / VoiceAgentBench**: these rank *models*, not custom agents — you'd submit a model choice, not our `gate_agent.py` architecture, so our commit-gate contribution wouldn't actually be measured. Not a fit for showing our work.
- **Artificial Analysis Speech-to-Speech Index**: also ranks base models (Gemini 3.8 Live, GPT-Realtime, etc.), not custom agents — same issue. Useful only as a citation for *why* we picked `gemini-3.8-live` as the reasoner (as `BUILD_PLAN_FDB_V3.md` already does), not as something we can "enter."
- **Everything else in the table** (v1/v1.5/v2, VoiceBench, FD-Bench): research benchmarks with no submission/entry process at all — cite them for context in the README's "results in context" section, don't attempt to run them.

**Bottom line for the README/slide:** FDB-v3 is the only one we can and do run our own agent against. The rest are useful purely as citations — for positioning ("no other public benchmark combines real disfluent speech + chained tool calls + full duplex") and for justifying the reasoner model choice — not as additional scored entries.
